# Plane — C# Windows Forms

A simple airplane control simulation using C# WinForms, airplane/light images, and WAV audio.

## Features

- Five orange buttons play their corresponding audio files.
- **GAS** moves the airplane upward; **Break** moves it downward.
- **ON/OFF** toggles the light effect and plays the switch sound.
- The images and sounds are included under `Plane/Assets` and automatically copied to the build output.

## Run

1. Use **Windows** with **Visual Studio 2022** and the **.NET desktop development** workload.
2. Open `Plane.sln`.
3. Build and run with **F5**. Requires the **.NET Framework 4.7.2 targeting pack** (Visual Studio can install it if missing).
